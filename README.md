# Action Juris AI Blog Importer

A specialized WordPress plugin designed to synchronize content from the Action Juris API.

## 🚀 Features

- **Smart Fetching:** Imports both Main and Sub-blogs.
- **Media Handling:** Downloads and sets Featured Images locally; hotlinks content images for performance.
- **SEO Ready:** Converts API separators (`|*|*|`) into proper `<h2>` and `<p>` tags.
- **Auto-Categorization:** Maps ISO country codes (gb, ca, us) to full country names and creates WP Categories automatically.
- **Internal Linking:** Resolves custom shortcode-style links `[text || slug || id]` into active WordPress permalinks.

## 🛠 Installation

1. Download the repository as a ZIP.
2. Upload to your WordPress site via **Plugins > Add New > Upload**.
3. Activate the plugin.
4. Go to **Tools > Import Action Juris Blogs** to begin.
